## **CRITICAL EXTRACTION GUIDELINES:**

### **Hierarchical Structure Rules:**
1. **Course** CONTAINS **Chapter** → **Chapter** BELONGS_TO **Course**
2. **Chapter** DIVIDED_INTO **Lesson** → **Lesson** PART_OF **Chapter**  
3. **Lesson** SUBDIVIDED_INTO **Section** → **Section** BELONGS_TO **Lesson**
4. **Section** INCLUDES **Topic** → **Topic** PART_OF **Section**
5. **Topic** COVERS **Content_Detail** → **Content_Detail** BELONGS_TO **Topic**

### **Learning Outcome Relationships:**
1. **CLO** CONTRIBUTES_TO_PLO **PLO**
2. **PI** MEASURES_PI **Performance_Indicator**
3. **Assessment_Method** EVALUATES_OUTCOME **CLO**
4. **Learning_Objective** ACHIEVES **Course_Objective**
5. **Course_Goal** ADDRESSES_CLO **CLO**

### **Assessment Chain:**
1. **Assessment_Component** CONTRIBUTES_TO_GRADE **Final_Grade**
2. **Grade_Component** WEIGHTED_AS **Weight_Percentage**
3. **Assessment_Task** ASSESSED_BY **Instructor**
4. **Grading_Criteria** DETERMINES_GRADE **Final_Grade**

### **Resource Dependencies:**
1. **Course** USES **Textbook**, **Software**, **Equipment**
2. **Lesson** UTILIZES **Learning_Material**
3. **Exercise** EMPLOYS **Tool**
4. **Student** STUDIES **Reference_Material**

### **Administrative Structure:**
1. **Course** OFFERED_BY **Faculty**
2. **Department** MANAGES **Course**
3. **Instructor** TEACHES **Course**
4. **University** GOVERNS **Faculty**

### **Prerequisites and Dependencies:**
1. **Prior_Course** PREREQUISITE_FOR **Course**
2. **Co_requisite** CO_REQUISITE_WITH **Course**
3. **Foundation_Knowledge** ENABLES **Advanced_Learning**
